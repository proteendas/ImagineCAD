# Building and testing

## Prerequisites

| | |
|---|---|
| Rust | 1.81 or newer (`rustup` recommended) |
| macOS | Xcode Command Line Tools (`xcode-select --install`) |
| Windows | Visual Studio Build Tools (MSVC); for LibreDWG, MSYS2 with `make patch curl tar xz mingw-w64-x86_64-gcc` |
| Linux | `sudo apt install build-essential libxcb-render0-dev libxcb-shape0-dev libxcb-xfixes0-dev libxkbcommon-dev libwayland-dev libgl1-mesa-dev` |

File dialogs on Linux use the XDG desktop portal (present on mainstream desktops).

## Build and run

```bash
cargo run -p imaginecad                    # debug build (dependencies optimised)
cargo run --release -p imaginecad          # release build
cargo run --release -p imaginecad -- drawing.dwg
cargo run --release -p imaginecad -- convert sketch.jpg -o out.pdf
```

## DWG support during development

Build the patched LibreDWG tools once and point ImagineCAD at them:

```bash
packaging/libredwg/build-libredwg.sh dist/libredwg          # add 'universal' on macOS for arm64+x86_64
export IMAGINECAD_LIBREDWG=$PWD/dist/libredwg
```

The script downloads LibreDWG 0.13.3 from ftp.gnu.org, verifies its SHA-256,
applies `packaging/libredwg/*.patch`, builds static `dwg2dxf`/`dxf2dwg`, and
copies LibreDWG's license and source notice alongside them.

## Quality checks (same as CI)

```bash
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
IMAGINECAD_LIBREDWG=$PWD/dist/libredwg cargo test -p icad-io --test dwg_roundtrip
```

### Screenshots and visual checks
The app can render itself and save a screenshot without OS screen-capture
permission:

```bash
IMAGINECAD_SCREENSHOT=shot.png target/release/imaginecad drawing.icad
IMAGINECAD_SCREENSHOT=shot.png IMAGINECAD_RUN="REC 0,0 @100,50;H 10,10 <ENTER>;ZOOM E" target/release/imaginecad
```

`IMAGINECAD_RUN` runs `;`-separated command lines (`<ENTER>` presses Enter).

## Third-party license notice

```bash
cargo install cargo-about --locked --features cli
cargo about generate packaging/licenses/about.hbs -o dist/THIRD_PARTY_LICENSES.html
```

Accepted licenses are listed in `about.toml`.

## Icons

`assets/` holds the logo in every format (`icon.png`, `icon-*.png`, `icon.ico`,
`icon.icns`), generated by `python3 packaging/scripts/make_icons.py`
(requires Pillow; `.icns` needs macOS `iconutil`).

## Installers

See [RELEASING.md](RELEASING.md). In short: `packaging/macos/build-dmg.sh`,
`packaging/linux/build-linux.sh`, and `packaging/windows/imaginecad.iss`
(Inno Setup). All three bundle LibreDWG when `LIBREDWG_DIR` (macOS/Linux) or
`dist/libredwg` (Windows) is present.
